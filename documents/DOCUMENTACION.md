# Entorno de Desarrollo

## Node.js

Entorno de ejecución de JavaScript orientado a Eventos Asíncronos.

**Ventajas:**

- Código JavaScript (ES6+)
- NPM con gran cantidad de paquetes
- Apps Monolíticas, API's, Micro Servicios

**Quién lo usa:**

- Netflix
- Uber
- PayPal
- LinkedIn
- Walmart
- NASA

[www.nodejs.org/es](https://www.nodejs.org/es)

**Versiones:**

- `node`: 24.x
- `npm`: 11.18.x

---

## Express

Framework para Node.js, muy minimalista y con opciones comunes para crear sitios web y aplicaciones.

La principal ventaja es que puedes instalar los paquetes que vas necesitando en tu aplicación y no vienen incluidos por defecto.

**Incluye:**

- Routing y Redireccionamiento
- Soporte a los diferentes Métodos HTTP
- Manejo de Errores
- Soporte de Template Engines

[www.npmjs.com](https://www.npmjs.com)
